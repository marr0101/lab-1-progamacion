# Laboratorio 1 — Diagnóstico técnico y flujo colaborativo

## Integrantes

- Hamal Riveros 
- Mariaelis Ortega 

## Objetivo

Realizar pruebas de consumo de una API pública mediante los métodos GET,
POST y DELETE, registrar los códigos de estado HTTP, aplicar principios
de Clean Code y utilizar un flujo colaborativo con Git y GitHub.


Durante el laboratorio se practicó el consumo de una API mediante
diferentes métodos HTTP, la aplicación de principios de código limpio
y el uso de GitHub para trabajar colaborativamente mediante ramas,
commits y Pull Requests.
